# Examples

All data in these examples are synthetic (fixed random seeds) and exist only to exercise the toolkit.

- `gallery/`: PNG output of `scripts/demo_gallery.py --target generic --formats png` (rerun without `--formats` to get the PDF and SVG masters locally) (estimation and paired plots, Kaplan-Meier cumulative incidence with risk table, subgroup forest plot, Bland-Altman, ROC and calibration, CONSORT and PRISMA flow, bars versus dot plot, diverging heatmap, ML ablation and training curves). Rerun with `--target jama`, `--target nature`, `--target aha`, and so on to see the same figures under each preset.
- `clinical-trial-schema/`: study-design schema built with the icon composer from `trial-schema.json` (clinical Lucide icons).
- `drawio-kernel-agent-loop/`: Scientific-Figure-Design's editable draw.io example (spec, frozen paper palette, figure contract, caption).
